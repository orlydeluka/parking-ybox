# חשבוניות למייל 📄➜📧

מקבל לינקים לחשבוניות שמגיעים ב-**SMS** או ב-**ווטסאפ** לאייפון, מוריד את החשבונית, ושולח אותה כקובץ **PDF** ל-`orlyg@timlul.com`.

## איך זה עובד

```
אייפון (קיצורי דרך)  ──לינק──►  שרת invoice-mailer  ──PDF──►  orlyg@timlul.com
  • SMS: אוטומטי                  1. הורדה ישירה אם הלינק הוא PDF
  • ווטסאפ: כפתור "שיתוף"         2. אחרת פותח את הדף בדפדפן ומחפש PDF / כפתור "הורדה"
                                  3. אם אין PDF מקורי – מדפיס את הדף ל-PDF
```

אפל לא מאפשרת לאפליקציות לקרוא SMS או הודעות ווטסאפ, ולכן החלק שבטלפון בנוי מ**קיצורי דרך** (Shortcuts) – אפליקציה מובנית באייפון, בלי צורך להתקין כלום:

| מקור | איך | מגע ידני? |
|---|---|---|
| SMS | אוטומציה שרצה על כל הודעה עם לינק | לא – אוטומטי לגמרי |
| ווטסאפ | כפתור בתפריט "שיתוף" | כן – 2 לחיצות |

עוד דברים שהשרת עושה:
- **סינון**: הודעות SMS עם לינק נשלחות רק אם יש בהן מילה כמו "חשבונית" / "קבלה" (ניתן לשינוי ב-`KEYWORDS`), כדי שלא יישלחו קודי אימות ופרסומות.
- **בלי כפילויות**: אותו לינק לא נשלח פעמיים במשך 30 יום.
- **אם הורדה נכשלת** – מגיע מייל עם הלינק, כדי לפתוח ידנית.
- **דף אינטרנט** בכתובת השרת להדבקת לינק ידנית (אפשר להוסיף למסך הבית).

## שלב 1 – סיסמה לשליחת מייל

השרת שולח את המייל דרך חשבון המייל שלך (SMTP). אם `timlul.com` הוא חשבון Google (Gmail / Workspace):

1. מפעילים אימות דו-שלבי בחשבון Google (אם עוד לא מופעל).
2. נכנסים ל-<https://myaccount.google.com/apppasswords>, יוצרים סיסמת אפליקציה בשם `invoice-mailer`.
3. שומרים את 16 התווים – זה `SMTP_PASS`.

> אם המייל מתארח אצל ספק אחר (Outlook / ספק אחסון), צריך את כתובת שרת ה-SMTP, הפורט והסיסמה שלו.

## שלב 2 – העלאת השרת לאינטרנט

הכי פשוט: **[Render](https://render.com)** (בערך 7$ לחודש בתוכנית Starter; התוכנית החינמית "נרדמת" ואז הבקשה הראשונה איטית).

1. נרשמים ל-Render עם חשבון GitHub.
2. **New → Blueprint** → בוחרים את הריפו `parking-ybox`. Render יקרא את `invoice-mailer/render.yaml`.
3. ממלאים `SMTP_PASS` (מהשלב הקודם) ומאשרים.
4. אחרי שהשרת עלה:
   - הכתובת שלו מופיעה למעלה, למשל `https://invoice-mailer-xxxx.onrender.com`.
   - את `API_TOKEN` שנוצר אוטומטית מעתיקים מלשונית **Environment**.
5. בדיקה: פותחים את הכתובת בדפדפן, מדביקים לינק לחשבונית ואת הטוקן, ולוחצים "שליחה למייל".

> אפשר להריץ גם בכל מקום אחר שתומך ב-Docker (Railway, Fly.io, שרת ביתי): `docker build -t invoice-mailer . && docker run --env-file .env -p 3000:3000 invoice-mailer`. רשימת המשתנים ב-`.env.example`.

## שלב 3 – SMS אוטומטי באייפון

באפליקציית **קיצורי דרך** (Shortcuts):

1. לשונית **אוטומציה** → **+** → **הודעה** (Message).
2. **ההודעה מכילה** (Message Contains): `http` → **הבא**.
3. בוחרים **הפעל מיד** (Run Immediately) ומכבים "הודע כשמופעל" אם רוצים שקט.
4. **אוטומציה ריקה חדשה** → מוסיפים פעולה **קבל את התוכן של URL** (Get Contents of URL):
   - URL: `https://<כתובת-השרת>/api/invoice`
   - לוחצים על החץ ◀ להרחבה:
     - **שיטה**: `POST`
     - **כותרות** (Headers): `Authorization` = `Bearer <API_TOKEN>`
     - **גוף הבקשה**: `JSON`, ומוסיפים שני שדות טקסט:
       - `text` = המשתנה **קלט קיצור הדרך** (Shortcut Input) – לוחצים עליו ובוחרים **תוכן** (Content)
       - `source` = `sms`
5. שומרים. מעכשיו כל SMS עם לינק לחשבונית יגיע למייל תוך כדקה.

## שלב 4 – ווטסאפ (כפתור שיתוף)

באייפון אין אפשרות לקרוא הודעות ווטסאפ אוטומטית, ולכן יוצרים כפתור בתפריט השיתוף:

1. קיצורי דרך → לשונית **קיצורי דרך** → **+**, שם: `חשבונית למייל`.
2. לוחצים על ⓘ (פרטים) ← מפעילים **הצג בגיליון השיתוף** (Show in Share Sheet). סוגי קלט: **כתובות URL** ו**טקסט**.
3. מוסיפים את אותה פעולת **קבל את התוכן של URL** כמו בשלב 3, אבל עם `source` = `whatsapp`.
4. (רשות) מוסיפים פעולה **הצג הודעה** (Show Notification) עם הטקסט "נשלח למייל ✓".

**שימוש:** בווטסאפ לוחצים לחיצה ארוכה על ההודעה עם הלינק → **העבר** → אייקון השיתוף ↗ → `חשבונית למייל`.
(או: לחיצה ארוכה על הלינק עצמו → **שתף** → `חשבונית למייל`).

> אותו כפתור עובד גם מ-Safari, מהמייל, או מכל אפליקציה אחרת עם לינק.

## API

`POST /api/invoice` עם `Authorization: Bearer <API_TOKEN>`

```json
{ "text": "החשבונית שלך: https://...", "source": "sms | whatsapp | manual", "wait": false, "force": false }
```

- `wait: true` – מחכה לסיום ומחזיר תוצאה לכל לינק (ברירת מחדל: מחזיר מיד `202` ומעבד ברקע).
- `force: true` – שולח שוב גם אם הלינק כבר נשלח.

## הערות

- יש אתרי חשבוניות שדורשים קוד אימות או התחברות – אותם השרת לא יכול להוריד, ויגיע מייל "לא הצלחתי" עם הלינק.
- השרת חוסם גישה לכתובות פנימיות ודורש טוקן, כך שאף אחד אחר לא יכול להשתמש בו.
- רשימת הלינקים שנשלחו נשמרת ב-`data/seen.json` (רק hash, לא הלינקים עצמם). ב-Render הדיסק מתאפס בכל פריסה – זה בסדר, במקרה הגרוע תגיע כפילות.
